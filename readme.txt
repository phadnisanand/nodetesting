SuperTest is a Node.js testing library for HTTP APIs
https://medium.com/@iamfaisalkhatri/api-testing-using-supertest-ea37522fa329

SuperTest is a Node.js library that helps in testing APIs. It extends another library called superagent, a JavaScript HTTP client for Node.js and the browser. You can use SuperTest as a standalone library or with JavaScript testing frameworks like Mocha.
